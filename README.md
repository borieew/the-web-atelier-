# The Web Atelier

A web design and development portfolio by Oluwabori Ayanbanjo. Explore selected projects, scan storefronts interactively, and check your store's readiness.

[Visit The Web Atelier](https://borieew.github.io/the-web-atelier-/)

## Website files

Keep `index.html`, the CSS and JavaScript files, and the `assets` folder in the root of the repository. The image files belong inside `assets/img/`. For example, the portrait should be at `assets/img/oluwabori.webp` and the VNDL Project desktop screenshot should be at `assets/img/vndl-desk.jpg`.

## GitHub Pages

In the repository, go to **Settings → Pages**. For **Source**, choose **Deploy from a branch**. Select the **main** branch and **/ (root)**, then click **Save**.
